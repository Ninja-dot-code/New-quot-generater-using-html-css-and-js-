# New Quote Generator

A simple quote generator built with HTML, CSS, and JavaScript.

---

## About the Project

This project displays random inspirational quotes.  
It is one of the early practice projects focused on DOM manipulation and arrays.

### Features
- Random quote display
- Clean UI
- Easy to extend with more quotes

---

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

---

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/Ninja-dot-code/New-quot-generater-using-html-css-and-js-.git
   ```
2. Open the main HTML file in your browser.
